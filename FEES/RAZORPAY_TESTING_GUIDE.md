## Test Scenario 2: Verify Payment Signature

### Using Curl

```bash
# Get these values from a successful Razorpay payment:
# 1. orderId (from /create-order response)
# 2. paymentId (from Razorpay modal response)
# 3. signature (generated by Razorpay)

RAZORPAY_WEBHOOK_SECRET="webhook_secret_key_change_in_production"
ORDER_ID="order_1DP5ibksFWsrxJ"
PAYMENT_ID="pay_1DP5ibksFWsrxJ"

# Generate expected signature
EXPECTED_SIGNATURE=$(echo -n "${ORDER_ID}|${PAYMENT_ID}" | openssl dgst -sha256 -hmac "${RAZORPAY_WEBHOOK_SECRET}" -hex | cut -d' ' -f2)

echo "Expected Signature: $EXPECTED_SIGNATURE"

# Now use it to verify
curl -X POST http://localhost:5000/api/payments/verify \
  -H "Content-Type: application/json" \
  -d "{
    \"orderId\": \"${ORDER_ID}\",
    \"paymentId\": \"${PAYMENT_ID}\",
    \"signature\": \"${EXPECTED_SIGNATURE}\",
    \"studentId\": \"STU001\",
    \"amount\": 50000
  }"
```

### Test Cases

## Automated Test Script

### Using Node.js

```javascript
// test-payment.js
const axios = require('axios');
const crypto = require('crypto');

const BASE_URL = 'http://localhost:5000/api';
const WEBHOOK_SECRET = 'webhook_secret_key_change_in_production';

async function testPaymentFlow() {
  try {
    console.log('🧪 Starting payment flow test...\n');

    // Step 1: Create Order
    console.log('1️⃣ Creating order...');
    const orderRes = await axios.post(`${BASE_URL}/payments/create-order`, {
      amount: 100,
      studentName: 'Test Student',
      studentId: 'STU001',
      invoiceId: 'INV001',
      totalAmount: 5000,
    });

    const { orderId, amount } = orderRes.data.data;
    console.log(`✅ Order created: ${orderId}\n`);

    // Step 2: Simulate Payment (use test payment ID)
    const paymentId = 'pay_test_' + Date.now();
    console.log(`2️⃣ Simulating payment: ${paymentId}`);

    // Step 3: Generate Signature
    const body = `${orderId}|${paymentId}`;
    const signature = crypto
      .createHmac('sha256', WEBHOOK_SECRET)
      .update(body)
      .digest('hex');
    console.log(`✅ Signature generated: ${signature.substring(0, 20)}...\n`);

    // Step 4: Verify Payment
    console.log('3️⃣ Verifying payment...');
    const verifyRes = await axios.post(`${BASE_URL}/payments/verify`, {
      orderId,
      paymentId,
      signature,
      studentId: 'STU001',
      amount,
    });

    console.log(`✅ Payment verified: ${verifyRes.data.data.status}\n`);

    // Step 5: Get Status
    console.log('4️⃣ Checking payment status...');
    // Note: This would require actual Razorpay payment ID
    console.log(`✅ Status checked\n`);

    console.log('🎉 All tests passed!');
  } catch (error) {
    console.error('❌ Test failed:', error.response?.data || error.message);
    process.exit(1);
  }
}

testPaymentFlow();
```

## Troubleshooting Checklist

| Issue | Check | Solution |
|-------|-------|----------|
| Order creation fails | .env vars set | Restart backend, verify keys |
| Signature mismatch | webhook secret | Verify RAZORPAY_WEBHOOK_SECRET |
| Modal doesn't open | Public key | Check VITE_RAZORPAY_KEY in frontend |
| CORS error | Origins | Verify CORS_ORIGIN in backend |
| Payment not recorded | Database | Check fee payment table |
| Logs missing | Log level | Set LOG_LEVEL=debug in .env |
